# Scraping-Prepocessing---Review-Stardew-Valley-from-Steam-Web-
Proyek ini berisi proses web scraping dan preprocessing data review game Stardew Valley dari Steam. Pengambilan data dilakukan melalui HTML scraping dan Steam API, kemudian data diproses melalui preprocessing teks dan divisualisasikan menggunakan WordCloud serta grafik distribusi Voted_up.
